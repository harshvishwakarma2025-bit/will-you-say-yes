# Will You Say Yes? ❤️

A fun interactive mini web project built with **HTML, CSS, and JavaScript**.

## ✨ Features

- 💖 Animated heart and romantic UI
- ❤️ Interactive YES button
- 😢 The NO button moves when the mouse gets close
- 😂 The NO button changes its text after each attempt
- 🎉 YES button grows as the user tries to click NO
- 📱 Simple responsive web interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📁 Project Structure

```text
Will-You-Say-Yes/
├── index.html

```

## 🚀 Run Locally

1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a web browser.

## 🌐 Publish Online

This project is a static website, so it can be hosted using services such as GitHub Pages or Netlify.
